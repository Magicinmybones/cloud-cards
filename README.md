# cloud-cards

Standalone static prototype from `cloud-cards(3).html`.

The deployable site is in `site/`. Embedded images and fonts were extracted to `site/assets/`.

## Deploy

```sh
npx wrangler pages deploy site --project-name cloud-cards --branch main
```

## Extracted assets

- `site/assets/fonts/font-1.woff2`
- `site/assets/fonts/font-2.woff2`
- `site/assets/images/image-1.png`
